# LuxStay - Website khách sạn (HTML + CSS + JS)
7 trang: index, gioi-thieu, loai-phong, thu-vien, danh-gia, tai-khoan, lien-he.
Thư mục anh/ chứa ảnh minh họa dạng SVG (tự vẽ). Muốn dùng ảnh thật: đặt ảnh .jpg cùng tên vào anh/ rồi dùng Find & Replace đổi ".svg" thành ".jpg" trong các file .html.
Dữ liệu đặt phòng, tài khoản, góp ý được lưu bằng localStorage của trình duyệt (bản demo, không có máy chủ).
Triển khai GitHub Pages: tạo repo > upload toàn bộ file (index.html ở thư mục gốc) > Settings > Pages > Deploy from a branch > main /(root).
